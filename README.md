## 使用

运行便携版 `bin/rapoo-tray.exe`，无需安装器。把 EXE 放到准备长期使用的位置，再按需开启右键菜单里的开机自启；移动 EXE 后需重新设置自启路径。

- 默认图标上行为鼠标、下行为键盘的数字电量；鼠标蓝色、键盘紫色，充电绿色，低电量红色，未知/断开显示灰色短线。0% 保留真实的零值。
- 悬停：状态卡分为鼠标、键盘两区；鼠标区显示电量、连接模式、DPI、回报率、休眠时间，键盘区显示电量、连接模式、亮度、灯效速度和无线休眠时间；移开后隐藏。连接标记独立居中；保留充电符号和未连接标记，无有效数值时显示横线，不重复解释未知／过期。
- 左键单击：异步刷新并显示双设备状态 4 秒；双击：循环切换“双数字 / 双电池条 / 数字加进度条”，不弹出样式提示，也不立即触发悬停卡片。三种样式均包含两台设备。原单设备三种样式已按用户要求移除。
- 右键：按鼠标、键盘分区显示型号和参数，删除重复的绿色连接标题；可设置鼠标回报率、休眠时间，以及键盘灯光亮度、灯效速度和休眠时间。主菜单和子菜单使用同一份状态快照，设备更新时同时刷新数值和勾选。另有低电量提醒设置、开机自启和退出。
- 键盘 USB 和 2.4G 均接入配置读取与设置：亮度 0/25/50/75/100% 对应硬件 0–4 档，速度也显示 0/25/50/75/100%，对应硬件 0–4 档；无线空闲休眠使用与鼠标相同的滑条及 5/10/30 分钟快捷按钮，滑条范围 1–120 分钟，USB 接线也可保存这项无线设置。设置前读取完整配置，仅修改目标字段，保留灯效、颜色和其他配置，再完整回读确认。菜单关闭后由主窗口显示约 2.2 秒结果提示，短暂防止悬停卡片覆盖；成功仅突出参数和设置值，不重复型号／电量／连接方式；失败只提示原因，不把目标值当作已生效值。静态灯效可能不体现速度变化；未识别的灯效布局拒绝修改灯光字段，不猜测字段。休眠设置 USB 10→5→10 分钟已实机回读验证，2.4G 休眠写入采用此前验证的完整配置页传输并通过模拟回归；实际长时间休眠/唤醒尚未测量。
- Fn＋↑/↓ 或 Fn＋←/→ 调整键盘亮度/速度后，程序读到实际配置变化时弹出百分比提示。健康连接下约每 3 秒检查灯光；连续操作显示最后读到的值，期间改了又改回可能不会提示。启动、重连、灯效切换、过期报告恢复及右键设置回读不重复提示。
- USB 额外监听已验证的厂商四字节变化通知；2.4G 接收已实录的 `0A/07` 配置变化通知及 `0A/02` 在线／离线事件，后者也触发状态回读。电量、灯效、亮度、速度和休眠数值来自查询回复；连接事件不直接恢复旧数值。合并通知后等待约 1 秒，只读核对状态，每分钟最多触发 4 次；无变化、失败或报告过多时停用该连接的通知刷新，保留原读取及退避。无线读取在查询/设置事务前暂停并排空，连接版本或模式变化后拒绝旧通知。严格格式检查及模拟回归已通过，新的连接事件运行行为尚未实机验收。不采集普通打字内容。
- “低电量提醒设置”：鼠标和键盘分别设置开关及两档阈值，默认 20% / 10%；严重阈值必须小于低电量阈值。每档在一个放电周期内显示一次，恢复至低电量阈值加 5 个百分点（上限 100%）后重新允许提醒；阈值为 100% 时重复满电报告不会反复弹出。排队时恢复、断开或充电会撤销旧提醒；同设备降到严重阈值时立即升级当前卡片。两台设备同时触发时顺序显示。

设置保存在当前用户的 `HKCU\Software\rapoo-tray`。双设备图标使用独立配置项，原版的图标选择不会被覆盖。自启动登记在当前用户 Run 键的 `rapoo-tray` 中，EXE 路径加引号，操作后检查回读。关闭开机自启动时保留登记，只切换本程序的 StartupApproved 状态，Windows 启动应用列表中的条目仍在；开启时恢复启用。菜单重新打开时读取系统状态，正常显示“已开启”或“未开启”，路径不匹配显示需修复；不支持的审批格式或访问失败显示状态未知并停止修改。目前接受不存在及12字节00/01/02/03记录：本机Windows实测00开启、01禁用，02/03保留兼容。程序与Windows双向关/开在本机实测通过，最终保持开启。StartupApproved不是微软公开的状态API，不宣称所有系统版本兼容；实际登录启动仍需独立验收。

鼠标、键盘各有一个后台控制任务线程，界面线程不等待设置读写。每个队列最多保留 8 个待办，同项未开始任务合并；已经开始的事务保留。设置期间对应菜单项暂不可操作，连接、模式、配置槽或灯效变化后拒绝旧结果。休眠滚轮停止 250 毫秒后提交最后的值，拖动仍在松手时提交，取消未提交调整不会写入。新读取与目标相同时跳过设置写入。退出时清除待办、通知读取线程停止并取消同步等待；底层驱动的取消完成时间仍由 Windows/驱动决定。

回报率直接读取鼠标状态包，休眠时间读取当前启用的配置槽。启动时不会把旧的本地休眠值写回鼠标。手动设置只修改当前槽，等待写入成功应答后再回读确认；成功时仅显示设置值和设备状态，不显示确认文字；发布结果时核对配置槽修订号和事务顺序，避免旧槽或旧读取覆盖当前设置；失败时分别提示未发送、写入应答失败、回读失败或配置槽变化；未确认的标题标明“尝试设置”，不会把目标值当作已生效值。可能已写入但未能确认时，旧的已确认值失效并显示未知。连接变化不会自动弹出 DPI 通知；真正切换 DPI 时仍有提示。

鼠标不再每隔 3 秒发送配置心跳，也不发送原先被称为“解锁”的固件版本查询。休眠时间在首次状态到达或配置槽变化后读取，点击刷新时最多每分钟读取一次；槽切换发生在限频期间时保留一次待办，限频到期后自动补读（最迟下个约 3 秒等待周期），不进行周期性配置轮询；控制接口请求失败后停止后台请求；手动设置允许一次有界恢复，先等待旧请求结束，再读取当前槽并写入，失败后至少间隔 2 秒才允许再次手动尝试。实际重新连接接口或重启程序也会恢复通道。读取失败显示未知，不会影响已收到的电量和回报率。右键菜单打开不等待硬件读取。

## 设备与连接

| 设备 | 连接 | VID:PID | 验证状态 |
| --- | --- | --- | --- |
| VT3S MAX 大师版 V2 | 2.4G | `24AE:146E` | 历史电量 100%、800 DPI；当前配置槽实机确认 2000 Hz / 7 分钟 |
| VT3S MAX 大师版 V2 | USB | `24AE:466E` | 实机读取 100% 和充电状态 |
| HI98C Pro | USB | `258A:010C` | 签名匹配，实机读取 100% 和充电状态 |
| HI98C Pro | 2.4G | `3554:FA09` | 签名匹配，实机读取 100%；充电标志尚未确认 |

同一设备两种接口均可读取时优先 USB；鼠标 USB 状态接口打开失败时回退到可打开的 2.4G 接收器，并保持对应接收器的控制接口。仅允许上述鼠标身份；键盘还必须通过型号签名检查，不能仅凭相同 VID/PID 认定兼容。

鼠标电量来自被动状态包，第一次状态包到达前显示未知；无线状态超过 3 分钟未更新时标为休眠或未连接，有线模式按实际 USB 接口判断。键盘电量仍每 60 秒查询；复用原读取线程独立调度每 3 秒只读检查身份及灯光配置（同页也包含休眠），不额外读电量、不延长电量时间戳。灯光检查失败按 15 秒、60 秒、5 分钟退避，常规电量查询不会绕过这个退避；断开时暂停快速检查；目标设备变化先合并等待并保留失败退避，手动刷新可提前恢复。新增的两个控制任务线程不增加正常轮询频率；电量读取失败按 5 秒、15 秒、60 秒、5 分钟退避重试，成功恢复 60 秒间隔，设备变化及恢复先合并等待并保留失败退避，点击可提前刷新，USB 查询只发送一次，发送和接收共用 150 毫秒预算，遇到尚未更新的响应头时只在剩余预算内重读，始终校验命令、参数和长度。偶发电量失败仅保留同一已识别连接模式下仍在原有 3 分钟有效期内的真实报告，不延长时间戳，不跨断开或模式切换沿用；过期电量不参与显示数值或提醒，首次没有报告时仍显示未知。灯光和休眠报告也遵守 3 分钟有效期；读取失败或配置不可用时显示横线并禁止写入，不显示缓存旧数值或重复状态说明；内存仍保留同模式且在有效期内的历史报告，不延长时间戳。快照只在进程内存中，没有持久电量缓存。

与官方键盘驱动同时访问时可能争用同一 HID 配置接口。本次驱动打开时休眠测试在写入前读取失败；退出官方键盘驱动后相同操作通过。这支持接口争用的判断，长期同时运行的兼容性仍未证明；遇到设置读取失败可先关闭官方键盘驱动，本工具不会自动重试写入或修改鼠标驱动。

本次实机测试的电量均为 100%。不同真实电量值、长时间休眠恢复及完全放电状态还需要持续实机验证；自动测试使用捕获的报文及边界变体验证解析和提醒规则，不代替这些硬件验证。

## 编译与测试

USB 查询的发送与接收共用 150 毫秒预算，超时或退出时取消异步 Feature 请求并等待取消结束，不接受迟到或截短回复。取消结束仍依赖 Windows HID 驱动响应，不能保证故障驱动的清理绝不超时。PnP 只处理本项目已支持设备的 HID 接口，键盘连续通知在约 1 秒后合并刷新（同一批最多等待 2 秒），保留失败读取的退避，失效快照不会立即重发。常规配置／电量轮询间隔仍为 3 秒／60 秒。

键盘配置暂未读到新值时，菜单和左键状态卡对应数值显示横线并禁用设置，不显示“配置暂未更新”或逐项状态后缀。恢复成功读取后自动恢复设置入口。上述代码与模拟验证不等于 USB 异常断连根因已确定或实机稳定性已验收。

Windows 10/11，MinGW-w64 或 MSVC，C++17；使用 Windows 原生 HID API，无额外运行时依赖。

```powershell
.\build.bat
.\tests\run_tests.ps1
.\tests\run_tests.ps1 -Render
.\tests\run_tests.ps1 -KeyboardUi
.\tests\run_tests.ps1 -Ui
.\tests\run_tests.ps1 -Smoke
```

构建输出为 `bin/rapoo-tray.exe`。编译失败返回非零退出码，保留上一份成功构建，不把旧 EXE 当成编译成功证据。UI 测试需要当前用户注册表写入权限，临时设置在测试退出时恢复；截图生成在 `verification/`。

默认测试和 `-Render` 不打开窗口、不访问设备；默认测试包含键盘 USB/无线模拟传输、整页读改写及错误应答拒绝。`-Render` 在离屏图面检查三种双设备图标、状态卡和菜单，显式指定渲染样式，不写注册表。`-KeyboardUi` 用真实窗口事件验证键盘菜单到结果提示的完整路径；窗口隐藏或置于虚拟桌面范围外，状态与设置后端均模拟，不访问硬件、不注册托盘、不写注册表。结果保存在 `verification/keyboard-ui/event-results.txt`。`-Ui` 和 `-Smoke` 会主动打开验证窗口；使用电脑时不要运行它们。运行主程序测试前先退出正在使用的同一托盘程序。中断 UI 测试可能打断配置恢复，应优先让其正常结束。

可运行 `获取鼠标PID.bat` 检查两个已支持鼠标接口；未知 PID 明确显示不支持，不再生成 PR 片段或修改剪贴板。检测到接口不等于成功读取电量。

硬件诊断工具（只输出相关接口及状态，不输出设备路径或序列号）：

```powershell
g++ -std=c++17 -O2 tools/device_probe.cpp src/hid_transport.cpp -lsetupapi -lhid -o bin/device_probe.exe
.\bin\device_probe.exe

g++ -std=c++17 -O2 tools/runtime_probe.cpp src/device_manager.cpp src/rapoo_protocol.cpp src/hid_transport.cpp src/keyboard_manager.cpp -lsetupapi -lhid -ladvapi32 -o bin/runtime_probe.exe
.\bin\runtime_probe.exe 30
.\bin\runtime_probe.exe 8 --passive
```

运行时工具采用与主程序相同的工作线程，只读取设置，不会应用旧的本地休眠值。`--passive` 禁用全部鼠标控制请求，仍正常查询键盘电量；此模式下鼠标休眠时间为未知。不要与主程序同时运行，以免诊断时竞争同一设备的报文。

图标设计参考 [LGSTrayBattery](https://github.com/andyvorld/LGSTrayBattery) 的数字电量与 [mouse_tray](https://github.com/Fan4Metal/mouse_tray) 的电量条思路；绘制代码独立实现。新图标设置使用 `DualBatteryStyleV2`，提醒设置使用 `DualBatteryAlerts`。

仍会显示的窗口/提示：左键或悬停状态卡、真正切换鼠标 DPI 的提示（单个主 DPI 数值及档位）、手动修改鼠标回报率/休眠的结果、键盘亮度/速度/休眠设置结果、读取到键盘快捷键或外部程序引起的亮度/速度变化、启用后的低电量/严重低电量提醒、手动打开提醒设置窗口、保存提醒时的无效阈值/保存失败提示、自启动操作或回读失败提示，以及启动读取线程失败提示。双击切换样式无提示；连接变化和后台查询不会主动弹出状态卡。设备数据恢复路径没有连接音效或系统气泡通知。
